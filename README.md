# 拾课 · 本地学习工作台

把本地学习视频变成可校对的课程全文，再围绕同一门课完成 **学习 → AI 出题 → 答题 → 分析与复习**。

拾课使用本机浏览器作为界面。视频转写、双模型复核、画面文字识别、题集保存与客观题判分在本地完成；出题和作答分析可以手动交给其他 AI，也可以配置模型供应商后在应用里调用。

![学习书架预览](docs/preview-bookshelf.jpg)

> 当前版本面向 **Apple Silicon Mac**，已在 **Apple M4 / 16 GiB 统一内存 / macOS 27.0.1** 上验证。仓库提供源码、文档和测试示例，模型与个人学习记录需要在本地下载或创建。截图中的课程和书架不会随源码自动导入。

## 能做什么

- **本地转写**：导入音视频，生成带片段时间范围的讲课全文，支持回放、人工校对和导出。
- **中英混合识别与复核**：默认使用 MiMo 4-bit 转写，再用 Whisper Large-v3 独立复核，列出两份识别的分歧。
- **画面资料**：提取可解码的内嵌文本字幕，用 macOS Vision OCR 识别画面文字，并保留对应画面供核对。
- **学习书架**：按书本封面管理课程，支持名称、封面、拖动排序和书内最多 8 层分类。
- **AI 出题与答题**：导入标准 JSON 题集；答案默认隐藏，可逐题展开解析、提交判分和导出作答。
- **分析与复习**：保存 AI 反馈与复习计划，也可直接调用已配置的模型供应商生成题集或分析作答。
- **三档速度**：快、中、慢档可在运行中切换；默认慢档，通过计算与冷却交替降低持续负载。

## 适配哪些电脑

以下说明针对当前源码、安装脚本和固定依赖，不能仅凭底层 Whisper 支持某个平台，就认为整套应用也已适配。

| 电脑或配置 | 当前适配情况 |
| --- | --- |
| Apple M4，16 GiB 统一内存 | 已验证默认 MiMo 转写、Whisper 复核、OCR 和完整学习流程 |
| 其他 Apple Silicon Mac，如 M 系列 MacBook Air / Pro、Mac mini、iMac、Mac Studio | 代码的目标平台；尚未逐机型实测，能否运行还取决于系统版本、依赖安装和可用内存 |
| 8 GiB 内存的 Apple Silicon Mac | 未验证默认双模型流程；可尝试 Tiny / Base / Small 的 CPU 模式，不能保证完整高精度方案可用 |
| Intel Mac | 当前整套安装与默认流程未适配；依赖清单包含 Apple Silicon MLX，不能直接按本说明安装使用 |
| Windows / Linux，包括带 NVIDIA 显卡的电脑 | 当前未适配；代码依赖 macOS Vision / PyObjC、MLX 和 Unix 进程控制，没有 Windows 或 CUDA 运行方案 |

### 系统、内存与空间

- **系统**：已验证环境为 macOS 27.0.1。当前本机安装的 `mlx==0.32.4`、`mlx-metal==0.32.4` wheel 标记为 `macosx_26_0_arm64`；旧版 macOS 的安装和运行没有验证。该标记是当前安装包的信息，不代表已确定所有依赖的统一最低系统版本。
- **内存**：默认方案以 16 GiB 配置为验证基准。模型按片段处理、串行加载，完成后退出子进程释放资源；实际用量受课程内容与其他运行程序影响。
- **硬盘**：默认三组模型文件合计约 10.2 GB，此外还需要 Python、依赖、缓存和课程数据空间。导入视频会复制一份到项目内，长课程还会产生画面资料。
- **Python**：`setup.sh` 使用 uv 在项目内安装 Python 3.12 并创建虚拟环境，无需预先配置系统 Python。
- **网络**：首次安装依赖、下载模型需要联网。下载完整后，本地识别和答题可离线使用；调用云端 AI 需要网络与对应账号。

**CPU 模式是当前 Mac 应用内的另一种识别方式，不是跨平台安装方式。** 选择它仍不会绕过安装脚本中的 MLX、Vision 等依赖。

## 安装、启动与停止

### 1. 获取源码并安装

从仓库页面下载 ZIP 并解压，或使用 Git 克隆到自己可读写的目录。在终端进入项目目录，执行：

```bash
cd /path/to/shike
bash setup.sh
```

将 `/path/to/shike` 换成实际路径。安装脚本优先使用 `requirements.lock.txt`，将 uv、Python、依赖和缓存放在项目目录中，不修改全局 Python、shell 配置或自启动项。使用预编译依赖包时，通常无需另外安装 Homebrew、Xcode 或系统 FFmpeg。

### 2. 启动应用

在 Finder 双击 **启动拾课.command**，或在项目目录执行：

```bash
bash 启动拾课.command
```

脚本会在运行环境缺失时尝试安装。浏览器自动打开本地界面，默认地址为 [http://127.0.0.1:8765](http://127.0.0.1:8765)。端口被占用时会尝试 8766–8784，以启动窗口显示的地址为准。

应用只监听本机 `127.0.0.1`，本地转写与答题无需注册应用账号或填写 API Key。它使用浏览器页面，没有独立打包的 `.app` 安装包。

### 3. 下载识别模型

可以在界面模型区域提前下载，也可以直接开始转写，由程序自动补齐所需模型。默认完整方案也可在安装后通过终端下载：

```bash
.venv/bin/python model_manager.py mimo-v2.5 whisper-large-v3-mlx
```

MiMo 所需的音频编码器会一并下载。模型保存在 `models/`；首次下载可能耗时较长。安装依赖不会自动下载全部识别模型。

### 4. 停止应用

双击 **停止拾课.command**，在启动终端按 `Control+C`，或执行：

```bash
bash 停止拾课.command
```

关闭浏览器标签页不会停止后台服务。

## 第一次使用

### 1. 建立书架并导入课程

在「学习书架」创建一本书，设置名称、封面和分类。导入时可选择归属书本和目录，也可稍后通过课程的「名称与归类」整理；未归类内容出现在「待整理课程」。

拖入本地音视频文件，选择语言、模型和运行速度，再开始转写。

| 项目 | 当前限制 |
| --- | --- |
| 视频扩展名 | MP4、MOV、MKV、WebM、AVI、M4V、MPEG、MPG |
| 音频扩展名 | MP3、WAV、M4A、AAC、FLAC、OGG、AIFF、AIF、OPUS |
| 单文件大小 | 最大 2 GiB，界面提示为 2 GB |
| 音轨长度 | 最长 2 小时，超出需先剪辑 |
| 任务容量 | 最多 4 个进行中或排队任务，转写任务按队列依次处理 |

扩展名可导入不代表任意编码都能解码或在浏览器播放。例如部分 MKV / HEVC 文件可能可以转写，但无法在页面预览，可用本地播放器回听。

### 2. 校对转写与画面资料

完成后，打开课程的「学习」页面：

- 在「时间轴」回听片段，在「课程全文」修改并保存最终文本。
- 在「复核」比较两份识别，选择保留主识别或采用复核文本。
- 在「画面资料」核对字幕、OCR 文字和保存的画面。

如果已经手动编辑过全文，请继续在全文中校对，再将分歧片段标为已核对；片段选择不会自动重写已有的人工全文。两份原始识别结果会保留。

语法课可能故意出现 `He go to school.` 这样的错误例句。应用关闭了 OCR 的文字纠正，但语音识别和 OCR 仍可能误识别，需要结合原视频确认。

### 3. 让 AI 出题

从课程进入「让 AI 出题」，选择下面任一方式。

**手动方式，无需在应用里配置密钥：**

1. 复制本课资料和出题格式，粘贴给自己使用的 AI。
2. 让 AI 按格式返回包含题目、答案和解析的完整 JSON。
3. 将 JSON 粘贴回本课并导入，题集会关联当前课程。

**直接调用模型供应商：**

1. 点击右上角「模型供应商」，新建连接。
2. 填写供应商标识、模型 ID、API Key；自定义兼容服务还需填写基础地址。
3. 保存后点击「测试已保存连接」。
4. 回到课程，选择连接与题数，点击「调用模型生成本课题集」。

供应商适配由 LiteLLM SDK 提供，界面从 SDK 读取供应商目录，支持原生适配器与 OpenAI 兼容接口。快捷配置包含 DeepSeek、通义千问、Kimi、OpenRouter、OpenAI、Claude、Gemini，以及本地 Ollama / LM Studio 的兼容接口。目录存在某项并不保证对应账号、模型或认证方式已经可用；高级云平台可能还需额外依赖。

Ollama / LM Studio 需要自行安装、启动并加载模型，拾课只连接其接口。云端出题、分析和连接测试可能计费。详细字段见 [模型供应商与自动出题、分析](docs/模型供应商与自动出题.md)。

### 4. 答题、判分与复习

在本课「答题」页完成练习，点击「提交并判分」。答案默认隐藏，每题附近均可展开答案与解析，也可一次展开全部。

| 题型 | 本地判分方式 |
| --- | --- |
| 单选、多选、判断 | 与标准答案比较；多选必须全部匹配，少选、多选不得分 |
| 填空：任一答案 | 接受预先列出的任意一个完整答案 |
| 填空：多个要点 | 必须答全指定要点，不计顺序 |
| 填空：数值范围 | 判断是否处于包含边界的数值区间 |
| 简答 | 保留回答与参考答案，交给 AI 或人工评价，不做本地语义评分 |

作答自动保存；看到保存成功提示后再关闭页面。当前每份题集保存最新作答，如需保留某次尝试，请先导出。

在「分析与复习」中，可以导出或复制作答给 AI，再粘贴保存反馈；配置供应商后，也可以直接点击分析按钮。导出的作答包含原题、自己的答案、参考答案、解析、本地判分及是否看过答案等信息。

本地判分是规则匹配，不能替代语义评价。答案隐藏用于自测，完整答案仍保存在本机题集文件里。

## 不下载模型也能先试答题

安装并启动应用后，打开「练习与答题」，导入 [docs/quiz-example.json](docs/quiz-example.json)，即可体验隐藏答案、作答、判分和导出。此过程不运行识别模型，也不需要模型供应商。

要体验转写，可导入 `tests/assets/学习方法示例.mp4` 或 `tests/assets/中英混合语法课示例.mp4`。`12分钟学习示例.mp4` 由重复讲解构造，适合检查长视频流程；这些素材不是实际课堂准确率的保证。`jfk.flac` 来自 [Whisper 官方测试样本](https://github.com/openai/whisper/blob/main/tests/jfk.flac)。

## 识别模型与速度选择

| 选择 | 当前实现与用途 |
| --- | --- |
| MiMo-V2.5-ASR MLX 4-bit，默认 | 中文、英文和中英混合主转写；支持启用 Whisper 独立复核与 OCR |
| Whisper Large-v3 MLX FP16 | 可独立转写，也可指定为任意语音任务的复核模型；复核是否开启由默认开关或本次任务决定 |
| Tiny / Base / Small / Medium / Large-v3-Turbo | 使用 faster-whisper 的 CPU INT8 模式；可搭配设置中指定的复核与画面识别模型 |

默认方案中，MiMo 权重约 4.51 GB，音频编码器约 2.6 GB，Whisper Large-v3 约 3.1 GB。GPU 模型使用独立子进程依次运行，不同时常驻。MiMo 在本项目中只接受中文、英文和混合语言；其他已提供的语言选项请使用 Whisper。

语音按停顿分成最长约 28 秒的片段处理，时间戳是片段范围，不是逐字精确对齐。术语提示作用于 Whisper，当前 MiMo 接口不使用该提示。没有证据表明默认方案对所有课程都优于其他方案，重要内容仍应人工复核。

| 速度 | 调度方式 |
| --- | --- |
| 快 | 正常情况下连续计算 |
| 中 | 约 35% 时间工作，其余时间冷却 |
| 慢，默认 | 约 5% 时间工作，其余时间冷却；系统报告偏热时等待 |

三档保持相同模型、量化精度、识别参数和复核设置，通过调度降低持续负载。慢档可能耗时很长；百分比是工作与冷却的调度目标，不是活动监视器中的精确占用率，也不保证固定温度。该设置不控制云端模型或独立运行的 Ollama / LM Studio。

OCR 约每秒抽样，忽略顶部约 15% 的常见弹幕区域，并去重重复画面文字；短暂文字、复杂公式、箭头和删除线可能遗漏或被误读。重叠音频去重也可能留下短语重复。进一步说明见 [升级使用说明](docs/升级使用说明.md)、[速度与低热模式](docs/速度与低热模式.md) 和 [本机验证结果](docs/验证结果.md)。

## 导出与数据存放

| 导出内容 | 用途与边界 |
| --- | --- |
| TXT | 保存后的课程全文；未编辑时使用片段选择后的文本 |
| Markdown | 全文、原始时间轴、画面资料、待核对分歧和运行指标 |
| SRT | 主识别原始字幕与片段时间；不包含 OCR，不随全文编辑重新对齐 |
| 出题提示词 | 按来源组织课程资料，附出题协议与未确认内容说明 |
| 课程 JSON | 原始识别、校对、画面资料和运行指标 |
| 题集导出 | 参考答案 Markdown、自己的作答 Markdown、完整记录 JSON |

长课程资料可能超过其他 AI 的上下文长度，需要分段处理。导出文本中的图片引用不会把图片本身打包；对应画面保存在任务的 `frames/` 目录。

应用管理的运行文件集中保存在项目内：

| 路径 | 内容 |
| --- | --- |
| `.runtime/`、`.venv/` | uv、项目 Python 与依赖 |
| `.cache/` | 模型下载及其他运行缓存 |
| `models/` | 识别模型与音频编码器 |
| `data/jobs/<任务ID>/` | 导入媒体副本、转写结果、日志与画面 |
| `data/library/` | 书架数据库和封面 |
| `data/quizzes/` | 题集、课程快照、作答和分析反馈 |
| `data/ai/` | 供应商连接与调用任务记录 |
| `data/performance.json` | 运行速度设置 |
| `data/app-settings.json` | 功能模型分配、默认复核/OCR 开关、按语言采用来源及自定义提示词模板 |
| `data/tmp/`、`data/server.log` | 临时文件与服务日志 |

模型、运行环境、缓存和 `data/` 已通过 `.gitignore` 排除，默认不会进入 Git 提交。公开仓库保留源码、文档和 `tests/assets/` 中的测试示例。

视频导入是复制到本项目。本地识别、OCR 和判分不调用云端 API；主动复制资料给外部 AI，或点击供应商出题、分析按钮后，相关文字才会发送到相应服务。供应商出题和分析发送课程文字或作答资料，不发送视频文件。

API Key 与高级认证参数以明文保存在 `data/ai/providers.json`，设置了当前账户的目录/文件访问权限，保存后不向页面回显，也不放入题集导出。备份 `data/` 时会包含这些敏感配置。

### 备份、迁移与卸载

- 停止应用后备份 `data/` 可保留学习记录、书架、题集与连接配置；同时保留 `models/` 可避免重新下载模型。
- 移动项目目录后需重建 `.venv` 并重新执行 `bash setup.sh`；已有模型和数据可以保留。
- 卸载时先停止应用，再删除整个项目目录。原始导入文件仍在原位置，项目内副本、模型和学习记录会随目录删除。
- 浏览器保存的下载文件与浏览历史由浏览器管理；导出文件保存到其他目录后不会随项目删除。

下表列出主要复用项目及其在应用中的职责。Python 依赖的具体版本以 [requirements.txt](requirements.txt) 和 [requirements.lock.txt](requirements.lock.txt) 为准。

| 项目 | 在拾课中的用途 |

## 开发与验证

安装依赖后，在项目目录运行：

```bash
# 自动检查，不需要下载识别模型或填写真实供应商密钥
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -q

# 真实 LiteLLM SDK 与本机模拟供应商联调，禁止外部网络
.venv/bin/python tests/check_ai_integration.py

# 启动本地服务但不自动打开浏览器
.venv/bin/python run.py --no-browser
```

如已安装 Node.js，可执行 `for file in static/*.js; do node --check "$file"; done` 检查前端脚本语法；Node.js 不是应用运行依赖。

自动检查覆盖题型判分、隐藏答案、文件导入、导出、分类、课程关联、模型供应商任务和调度等逻辑；真实识别质量需要另用模型与音视频素材验证。已有实测记录见 [本机验证结果](docs/验证结果.md) 与 [三档速度验证](docs/速度与低热模式.md)。

主要源码入口：`app.py` 提供接口与队列，`worker.py` 编排识别，`stage_runner.py` / `cpu_stage.py` 运行模型，`visual_extract.py` 提取画面资料，`library.py` 管理书架，`quiz.py` 管理题集与判分，`ai_service.py` 对接供应商，`static/` 提供浏览器界面。

## 常见问题

**安装失败或提示没有匹配的依赖包？** 先确认是 Apple 芯片 Mac，并使用项目脚本安装。当前没有面向 Intel、Windows、Linux 或旧版 macOS 的兼容依赖清单；不要仅凭切换 CPU 模型判断安装已兼容。

**双击脚本没有运行？** 在项目目录用终端执行 `bash 启动拾课.command`，查看具体错误；需要补齐依赖时重新执行 `bash setup.sh`。

**一直显示下载或识别很慢？** 首次使用需要下载数 GB 模型；默认慢档还会插入大量冷却时间。查看任务当前阶段、冷却倒计时和日志，按需要切换到中档或快档。

**离线时能不能使用？** 完整安装依赖并下载相应模型后，可以离线转写、校对、导出和本地答题。生成新题目或做 AI 语义分析，需要手动使用其他 AI，或连接一个可用的本地/云端模型服务。

**能否直接粘贴在线视频链接？** 当前输入是本地音视频文件，没有视频站点下载器。请先取得自己可使用的本地文件再导入。

**为什么全文修改后 SRT 没有同步变化？** SRT 保留主识别原始字幕及片段时间，不根据人工全文重新对齐；校对后的正文请导出 TXT 或 Markdown。

详细操作还可参考 [AI 出题与本地答题](docs/AI出题与本地答题.md) 和 [书架与课程学习流程](docs/书架与课程学习流程.md)。


## 工作台设置

右上角 **设置** 分为「模型与复核」和「提示词模板」。完整操作与接口说明见 [设置使用说明](docs/设置使用说明.md)。

- 默认复核、画面识别开关会用于后续新任务，也可在工作台临时修改，并点击「将本次模型与开关设为默认」。关闭复核时不执行第二个语音模型。
- 复核后可保留主转写、人工检查分歧，或按中文、英文、中英混合、其他语言分别选择主转写 / 复核来源。初始偏好为中文 MiMo、英文 Whisper、中英混合 MiMo（对应初始模型分配）；只有选择按语言自动采用时生效。两份原始结果保留，可人工改选；默认采用不等于已确认正确。
- 语音主转写、语音复核、画面识别、出题、分析可分别选择本地模型或供应商连接。先在「管理供应商连接」勾选该模型实际支持的文字、语音转写接口、视觉对话用途。用途由用户声明，并不保证供应商模型兼容；联网语音复用 LiteLLM `atranscription`，图片识别复用其视觉对话适配器，不是所有对话模型都支持语音转写接口。
- 全部使用供应商连接时隐藏运行速度；混用时档位只作用于本机原生推理。本机 HTTP 模型服务（Ollama 等）的负载由该服务控制。联网语音会发送音频片段，联网画面识别会发送抽取画面，点击开始前可查看数据发送说明。
- 可查看与修改出题格式、出题系统提示、分析系统提示、作答分析要求、联网语音提示、画面识别提示，另存多个自定义模板并设默认，也可恢复内置默认。JSON 题集协议仍为 version 1。本地语音解码参数不受提示词模板影响。

本次设置改造通过 71 项自动化测试；隔离联调使用真实 LiteLLM SDK 请求本机模拟供应商，验证了出题、作答分析、队列语音主转写与复核、图片识别、按语言采用和联网跳过速度限制。测试未使用真实供应商密钥，不代表特定云端模型的识别质量。
