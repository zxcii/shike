# AI 出题与本地答题

1. 在转写工作台完成校对后，点击「复制内容，让 AI 出题」。资料中已包含课程来源和下列题目协议。也可以在「练习与答题」单独复制 AI 出题格式，然后附上自己的学习资料。
2. 将资料发送给你选择的 AI，要求按协议生成完整 JSON，**包含答案和解析**。
3. 在「练习与答题」粘贴 AI 返回的完整 JSON，或者打开 JSON 文件，点击「导入并开始答题」。支持一个完整的 `json` 代码块包裹；不接受混在正文中的片段。错误时会提示 JSON 位置或具体题目字段，原导入文本保留。
4. 答案默认隐藏。作答时自动保存在本项目 `data/quizzes/`，重启后可从「本地题集」选择继续。看到「作答已保存在本机」后再关闭页面。保存失败会保留页面上的输入，可点击重试。
5. 点击「提交并判分」。结果显示在每题上方；每题下方可展开自己的参考答案和解析，也可一次展开或隐藏全部。题号导航可直接跳题，不需要到文末寻找答案。
6. 可以修改后重新提交，或清空作答。当前版本保存每份题集的最新作答；希望保留某次尝试时先导出。查看过答案的题目会保留「曾查看答案」标记，即使后来隐藏或清空作答也不会消失。
7. 「导出我的作答（给 AI）」或「复制作答给 AI」会包含原题、选项、自己的回答、标准答案、解析、本地分数及查看答案标记。交给 AI 进一步评价，特别是简答与语义合理但未精确匹配的填空。尚未提交也可导出草稿。

无需另外运行大模型即可答题与判分。上述手动流程不调用云端模型；也可使用新增的「模型供应商」连接，在课程内明确点击按钮直接调用模型。详见 [模型供应商与自动出题](模型供应商与自动出题.md)。

## 题集协议 v1

可直接复制 [quiz-example.json](quiz-example.json)，它包含五种题型及三种填空规则。界面的「查看格式」会显示可直接给 AI 的完整说明与这个示例。

根对象：

| 字段 | 规则 |
| --- | --- |
| `version` | 整数 `1` |
| `title` | 非空题集名，最多 200 字 |
| `description` | 可选的题集说明 |
| `questions` | 1～200 道题的数组 |

所有题目必须包含 `id`、`type`、`prompt`、`points`、`explanation`。`id` 唯一，只含字母、数字、下划线或短横线。`points` 大于 0 且不超过 100，省略时默认 1。每题必须有参考答案和解析，题干用 `prompt` 表示。导入最大 1 MB。

| type | 答案格式与判分 |
| --- | --- |
| `single_choice` | `options` 各项为 `{"id":"A","text":"选项内容"}`；`answer` 为一个有效选项 id 字符串 |
| `multiple_choice` | 同上，`answer` 为有效选项 id 数组，不计顺序；必须集合完全一致，少选、多选均不得分 |
| `true_false` | `answer` 为 JSON 布尔值 `true` 或 `false`，不能写成字符串；未选择与选择「错误」分别处理 |
| `fill_blank` | `blanks` 按题干空位顺序排列，每项含 `label` 与 `answer` 规则对象；每空等分，可部分得分 |
| `short_answer` | `answer` 为参考答案文本。本地不做语义评分，该分值单列为「待 AI 评价」，不计入自动判分分母 |

填空规则对象：

| mode | 示例 | 语义 |
| --- | --- | --- |
| `any_of` | `{"mode":"any_of","values":["AI","artificial intelligence"],"case_sensitive":false}` | 学生写任意一个列出的完整答案即可，不能把多个候选全部写上碰运气 |
| `all_of` | `{"mode":"all_of","values":["2","3"],"case_sensitive":false}` | 必须答全所有要点，以换行、英文或中文分号分隔，不计顺序；缺少、额外、重复要点均判此空错误 |
| `number_range` | `{"mode":"number_range","min":3.13,"max":3.15,"unit":"弧度"}` | 包含上下界，学生只输入数值；单位只作提示。精确数字可令 min 等于 max |

文本答案统一全半角，去除首尾空白、合并连续空白；默认忽略大小写。`case_sensitive:true` 可要求区分大小写。不自动删除标点，不进行模糊语义判分。同义表达要在 `any_of.values` 中明确列出。开放表达宜使用简答题。

数值支持小数、正负号与科学计数法；不接受 NaN、Infinity、千位逗号或附带单位的输入。百分数须在题干和单位中明确尺度，例如以 `%` 为单位时 50% 输入 `50`，范围也用同一尺度。

## 保存与导出

- 题集、参考答案、当前作答、判分和查看标记统一存入 `data/quizzes/<id>.json`，没有浏览器外部账户依赖。提交和保存采用修订号防止多个页面互相覆盖；发现冲突会报错并保留当前页面输入。
- 修改答案会清除此前判分，需重新提交；不会在输入过程中提前透露对错。
- 默认接口响应不含未展开的参考答案与解析。答案在本机题集文件中完整保存；这里的隐藏用于自测，不是考试防作弊功能。
- 「导出参考答案」得到 Markdown，每题后紧跟答案和解析。
- 「导出我的作答」得到可给 AI 的 Markdown，未提交时标记为草稿。
- 「导出完整记录 JSON」包含题集、答案、作答和评分元数据，便于归档。它是完整记录，不是 v1 题集输入对象；重新导入题目时取其中的 `quiz` 对象。
- 本功能只新增普通文本文件，不调用识别模型，不增加 GPU 计算负载。

## 验证

运行 `.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -q`，覆盖题型判分、填空等价答案/多要点/数值边界、隐藏与逐题展开、保存、修订冲突、导出、跨站请求限制和原有转写功能。
