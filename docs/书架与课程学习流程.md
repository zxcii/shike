# 书架与课程学习流程

## 按一门课程完成学习

从「学习书架」打开课程后，页面顶部始终保留课程名称、所在书本/多级目录和四步导航：

1. **学习课程**：播放视频，阅读转写，校对与保存。
2. **让 AI 出题**：复制本课内容和题集格式给 AI；将 AI 返回的完整 JSON 粘贴到本课。题集会自动关联当前课程。已有的独立题集也可以在这里关联。
3. **开始答题**：题集下拉列表聚焦本课的练习。原有逐题判分、隐藏答案、查看解析和导出功能保留。每次导入是独立题集，不会覆盖以前的作答。
4. **分析与复习**：显示当前题集自动得分、完全答对题数、简答待评价分值及参考答案查看情况。点击值得回看的题目可跳回对应答题位置，或回看原课程。复制/导出资料给 AI 评价，再将 AI 的反馈或自己的复习计划粘贴保存到本题集。

自动统计不是大模型分析，也不等同于课程掌握度。可手动将资料发给 AI，也可配置模型供应商后明确点击调用按钮，直接出题与分析；未配置时保持手动方式。保存后的分析若对应的作答被修改，会标记为旧反馈，提示重新评价。

题集包含来源课程标识、出题时的课程内容快照及快照时间。用于 AI 评价的导出包含口述、画面/字幕资料和待核对分歧的分区快照、原题、自己的回答、参考答案、解析及本地判分。即使日后修改转写或删除原视频记录，已保存的题集与快照仍保留。列表中的课程显示名可修改，不影响原始文件名和视频副本。

原有「练习与答题」入口仍可查看全部题集，支持没有课程来源的独立练习。它们可以在课程的「让 AI 出题」页关联；不会自动猜测已有题集属于哪一课。

## 一本书是一级分类

「学习书架」按一本本封面展示主题。每本书可设置名称、简介、六种默认文字封面配色，或上传 JPG、PNG、WebP 封面（5 MB 内、2000 万像素以内）。上传图片会本地缩放并转为 JPEG，保留原始用户文件。

- 可以拖动封面旁的排序把手重排书架，也有前移/后移按钮。
- 点击书本进入目录。书内最多支持 **8 层分类**，支持创建、重命名、修改上级、拖动调整层级、搜索目录。
- 选择目录后可包含或排除子目录里的课程。不能把目录移进自己的后代，也不能跨书拖动目录；将整门课程移到其他书请使用「名称与归类」。
- 分类仅在没有课程和子分类时可以删除，避免连带删除学习数据。
- 课程卡片显示学习、出题、答题、分析的进展。点击「名称与归类」可改课程显示名、所属书、目录及已学习标记。
- 导入新视频前可直接选择目标书本和目录。已有课程的归类显示在工作台中，修改请用课程顶部的「名称与归类」。
- 没有分类的原有课程统一出现在「待整理课程」，不需要重新转写。模型下载记录另行折叠，不占用课程书架。

书架搜索会匹配书本名称、简介及课程显示名；书内搜索还会匹配课程原文件名和分类路径。

## 数据与组件

所有数据仍位于本项目：

- `data/library/library.sqlite3`：书本、分类、课程位置与显示名。
- `data/library/covers/`：本地封面图片。
- `data/jobs/`：现有视频副本和转写记录。
- `data/quizzes/`：题集、来源快照、最新作答、本地判分和保存的分析。
- `static/vendor/`：固定版本 jsTree、SortableJS、jQuery 和许可证。运行时不依赖 CDN。

开源来源和许可见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。目录交互使用 jsTree，书架排序使用 SortableJS；分类存储使用 Python 自带 SQLite。

测试覆盖书架编辑、目录循环与 8 层边界、移动子树深度、跨书分类拒绝、排序事务、封面校验、上传时归类、课程来源、快照、分析过期提示及原有转写/答题功能。界面验证使用已有的学习示例课程，不需要再次运行识别模型。
