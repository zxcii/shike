# 高精度版使用说明

默认选择「MiMo · 中英高精度」与「中英混合 · 保留原文」，并启用独立复核和画面识别。

## 完全本地的处理阶段

1. 读取音轨、分成约 28 秒以内的语音块，边界保留少量上下文。
2. macOS Vision 提取画面字幕与英文例句，关闭文字纠正，保留关键帧。可解码的文件文本字幕轨也会单独保留。
3. MiMo-V2.5-ASR MLX 4-bit 在 Apple GPU 上完成主识别。
4. MiMo 子进程退出后，Whisper Large-v3 MLX FP16 再独立识别相同片段。
5. 显示识别分歧，供回听、比较与人工校对。模型不自动改写语法错误。

模型串行运行；取消或停止服务会结束整组进程，包含 GPU 推理子进程。MLX 控制缓存并遵守设备推荐内存，不调整系统 GPU 内存限制。首次模型下载联网，实际识别子进程设置离线模式，所有模型和编码器使用本地路径。

## 新增界面

- **复核**：主识别、复核文本并排提供；英文词差异也会提示，例如 `go/goes`、`is/was`。可以保留主识别、采用复核，或在全文校对后标记已核对。两份原始文本均保留。
- **画面资料**：与口述分开显示 OCR、文件字幕轨及原始关键帧。点击原图可核对拼写、颜色或删除线。
- **内存指标**：完成后显示每个模型进程的 GPU 峰值与 RSS 峰值，口径不同，不应直接相加。
- **出题资料**：分开附带口述、画面资料与待确认分歧，要求其他大模型保留错误例句，不据未确认内容判分。

保存过整份全文后，不允许「采用复核文本」覆盖人工全文；请在全文中修改，然后标记片段已核对。

## 文件和大小

MiMo 4-bit 权重约 4.51 GB，音频编码器约 2.6 GB，Whisper Large-v3 权重约 3.1 GB。权重大小不等于运行内存。M4 / 16 GiB 采用分段和单 GPU 子进程依次运行。

- `models/`：全部模型与编码器。
- `data/jobs/<任务ID>/frames/`：有文字的原始画面。
- `data/jobs/<任务ID>/job.json`：两份原始转写、片段选择、全文校对、OCR、来源与实测指标。
- `worker.py`：流水线调度。
- `stage_runner.py`：单一 GPU 模型进程。
- `model_manager.py`：本项目内模型下载与编码器相对路径绑定。
- `visual_extract.py`：Vision OCR、关键帧和文本字幕轨。
- `pipeline.py`：分块、重叠与英文差异检查。

## 导出与限制

TXT 使用保存的全文；没有全文编辑时，使用片段校对后的文本。Markdown 和出题提示词另外包含画面来源、待核对分歧。JSON 保留完整信息。SRT 保留主识别原始片段，不跟随全文改写，不包含 OCR。

MiMo 时间戳是音频块范围，并非逐字精确对齐。OCR 每秒抽样、排除常见顶端弹幕区域、对重复文字去重；短暂文字、复杂公式、箭头、颜色、删除线可能遗漏或失真。OCR 和语音相同或两模型一致，都不能证明内容一定正确。

社区 4-bit 版本不等于官方全精度评测模型。真实课堂需回听校对，测试素材通过合成语音生成，不能作为实际准确率保证。

## 验证命令

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -v
node --check static/app.js
.venv/bin/python tests/create_mixed_fixture.py
.venv/bin/python tests/check_ocr.py
# 本地服务需已启动
.venv/bin/python tests/smoke_accurate.py
```

原有启动、停止、导入上限和删除方式不变。先双击停止脚本，再删除整个项目目录，即可删除本应用代码、运行环境、模型、缓存和学习记录。原视频不受影响。

重叠音频用于保留边界上下文，保守去重可能留下少量短语重复，需在全文校对。
