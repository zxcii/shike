# 中英混合学习课程的本地识别方案

选择日期：2026-11-04。

## 选择结论

面向英语兔《英语语法精讲合集》这类中文讲解、英文例句、画面文字同时出现的学习视频，选择：

- 主识别：MiMo-V2.5-ASR，使用社区转换的 `mlx-community/MiMo-V2.5-ASR-MLX-4bit`，通过 MLX 在 Apple Silicon 上推理。
- 独立复核：Whisper Large-v3，使用 MLX 的 FP16 版本，关注英文例句、否定词、词尾、时态、人名和术语上的分歧。
- 画面辅助：macOS Vision OCR，提取画面中的字幕与英文例句；保留关键帧，文字与语音分别标注来源。
- 运行方式：各阶段串行、独立进程、短音频分段处理。一个模型退出并释放内存后，再启动下一个模型。

这是根据任务、硬件、公开模型说明和运行库支持作出的工程选型，不是对这段视频进行逐字评测后的冠军结论。社区 4-bit 版本不能直接继承原始全精度模型的全部评测成绩。

## 已核实的电脑配置

- Apple M4，10 个物理 CPU 核心。
- 16 GiB 统一内存。
- arm64，macOS 27.0.1。
- 项目所在磁盘可用空间约 310 GiB（检查时）。

MiMo 4-bit 的 ASR 权重约 4.51 GB，**另外还需要音频 tokenizer、运行缓存和激活内存**。权重大小不等于进程峰值内存。硬件与 MLX 架构兼容，4-bit 模型存在可用的本地部署路径；稳定运行与具体峰值仍须下载后实测。不能把“16 GB 内存”理解成可给 GPU/模型独占 16 GB。

不选择 MiMo 的完整 BF16/FP32 权重作为本机默认部署版本。是否能够升级到 8-bit，需要包含音频 tokenizer 和推理缓存的实测结果，不能只按参数数量推算。

## 处理流程

1. 导入本地视频，保留原始文件副本。若文件包含独立字幕轨，先提取并检查它是原文字幕还是译文字幕。
2. 解码音轨，进行语音活动检测；按停顿构造约 20–30 秒音频块，边界保留约 1 秒上下文，避免切断英文词或句子。原始时间偏移始终保存。
3. MiMo 主识别采用自动/混合语言模式，不强制把中文、英文全部输出成单一语言。英文例句保持英文。
4. 对视频变化帧和字幕变化帧做 OCR；限制字幕区域、屏蔽顶端弹幕，做时序去重。课件例句与口述内容分开保存，OCR 不会自动被当作老师说过的话。
5. 卸载主识别模型后，加载 Whisper Large-v3，独立识别同一段音轨。结果不一致时，展示两份候选文本、对应画面和回听时间。
6. 对跨块重复文本做保守去重。不能仅凭两个结果相同就宣布正确；不能在没有依据时自动猜测分歧词。
7. 输出原始转写、画面补充、待校对片段、用户保存的校对全文。交给出题模型时要求引用资料出处，并保留未确认之处。

精细字词时间戳如有需要，可在转写文本确认后追加独立强制对齐阶段。强制对齐负责时间位置，不负责证明转写内容正确。

## 为什么这样选择

MiMo 官方将中英 code-switching、知识密集内容和英文复杂场景列为目标能力，符合这类课程的需求；社区已经提供 Apple Silicon MLX 的 4-bit 权重。Whisper Large-v3 作为不同模型的复核来源，可提供独立候选结果，但双模型不能保证自动纠错。

Qwen3-ASR-1.7B 是更轻的备选方案，其官方中英文单语评测很有竞争力。不过官方仓库也有中英文切换时语言误判或翻译的用户报告，所以不能只凭单语排名把它认定为该混合课程的最佳单一引擎。

本次查看了视频页面、课程目录和带画面字幕的预览；没有下载完整视频，也没有对其音轨进行准确率实测。

## 语法课必须保留的信息

- 示例中的 `a/an`、`is/was`、`do/does`、否定词与词尾。
- 老师逐个念出的字母、词形变化和中英文切换。
- 老师故意展示的错误句、对比例句和被划掉的句子。不得用通用大模型自动“润色成语法正确”。
- OCR 可能看不懂颜色、箭头、删除线的教学含义，因此关键帧应和文字共同保留。

## 上线前的验收标准

- 用本地中文、英文、句内中英混合的真实课程片段分别验证；英语例句按词检查，中文讲解按字检查。
- 在本机测量峰值内存、Metal 可用资源和交换内存；覆盖最长音频块与反复加载卸载，不只测试模型能否加载。
- 对 10–20 分钟视频验证片段边界无漏句、重复，字幕时间不超出视频时长。
- 验证断网运行；所有模型、tokenizer、运行依赖、缓存和记录仍保存在当前项目目录。

## 当前 App 状态

已接入 MiMo 4-bit 主识别、Whisper Large-v3 GPU 独立复核和 macOS Vision OCR；所需模型均已下载。原 Small/Base CPU 模式及历史记录保留。界面增加复核、画面资料、片段选择和内存指标，使用方法见「升级使用说明.md」。已通过本机混合语音、故意错误例句、OCR、双模型和导出的真实流程验证；实际课堂准确率仍须回听校对。
