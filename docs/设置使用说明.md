# 工作台设置

入口：右上角「设置」。设置保存在本项目 `data/app-settings.json`，供应商连接与认证仍保存在 `data/ai/providers.json`，删除项目即可一并删除。

## 复核与默认开关

「开启独立语音复核」与「开启画面识别」分别保存为新任务的默认值。本次临时选择不会影响以后；在工作台点击「将本次模型与开关设为默认」可保存当前选择。已有任务重试时保留它创建时的模型与转写提示词。

关闭复核只运行主转写；关闭画面识别不提取画面或字幕轨。开启复核后可以选择：

- 保留主转写，分歧由我核对：保留原有工作方式。
- 按语言自动采用我信任的来源：为中文、英文、中英混合、其他语言选择主转写或复核文本。初始主转写 MiMo、复核 Whisper；可按功能改选模型。自动识别按片段文字和语言标记分类；显式内容语言优先。混合内容整段采用一个来源，不拼接词句。

「默认采用」不是人工确认。复核页始终展示两份结果；任务完成后可以改选，已经手动编辑全文的课程不会被自动覆盖。空结果不会抹掉非空主转写。有分歧的自动选择也会在出题资料中标注来源和未经人工确认。

## 功能与模型

五个功能分别配置：语音主转写、独立语音复核、画面识别、AI 出题、AI 分析。

本地语音支持现有 MiMo、Whisper MLX 和 faster-whisper 系列；画面可以使用本机 Apple Vision。出题和分析可选供应商连接、本机模型服务，或仅手动复制。

供应商连接复用 LiteLLM SDK。每份连接对应一个模型，在「此模型支持的用途」中勾选实际支持的功能：

| 用途 | 实际调用 | 用于 |
|---|---|---|
| 文字对话 | `acompletion` | 出题、分析 |
| 语音转写接口 | `atranscription`，16 kHz 单声道 WAV，最长约 28 秒片段 | 主转写、复核 |
| 图片识别 | `acompletion` 的 `image_url` 图片输入 | 课程画面文字 |

对话模型不一定支持音频转写接口，即使它具备音频理解能力也需确认具体供应商适配。用途勾选是声明，不会把普通文本模型转换成语音模型。模型目录仅为 SDK 随包参考，可手填语音/视觉模型 ID；高级云平台可能需要安装额外官方依赖到项目虚拟环境。

全供应商任务不加载本地 ASR，不启用模型快、中、慢档调度。音轨解码、语音活动检测和画面抽取仍在本机，仍有少量 CPU 工作。混用时，速度档位只控制原生本地计算。通过本机 HTTP 运行的模型服务需在对应服务中控制负载。

开始按钮旁说明将发送哪些资料。联网主转写/复核发送音频片段及所选语音提示、术语；联网画面识别发送抽取的画面及画面提示。出题与分析发送对应文本，不自动上传视频原文件。可能产生供应商费用，不自动重试或切换备用供应商。没有真实供应商密钥时，应用无法验证该供应商模型的实际效果。

## 自定义提示词

「提示词模板」可编辑六类提示词：出题格式与要求、出题系统提示词、分析系统提示词、作答分析要求、联网语音转写提示、画面文字识别提示。

选择用途后查看模板，修改名称与正文，点击「另存为模板并设为默认」。自定义模板可以原地保存；内置模板只能另存，便于恢复。选择已有版本后「将此模板设为默认」；「恢复内置默认」不会删除自己的模板。

出题格式用于手动复制、课程出题资料导出和直接调用。分析要求用于复制作答、导出作答和直接分析。系统提示用于联网对话；语音和画面提示随新转写任务保存快照，不影响已经创建的任务。本地原生语音保持现有解码参数，术语提示仍按原有模型支持情况生效。

可调整教学风格、题型比例、难度和分析重点；程序继续按既有 version 1 JSON 协议校验与判分。删除或改变必需字段会导致导入失败。改模板不重写已有题集、答案、反馈。

## 验证

运行 `.venv/bin/python -m unittest discover -s tests -p 'test_*.py'` 执行自动化测试。设置新增测试覆盖保存、版本冲突、模板切换、导出采用、用途匹配、全部联网无速度档位、关闭阶段不解析失效连接、按语言选择、手工保护与空结果保护。

运行 `.venv/bin/python tests/check_ai_integration.py` 使用实际 LiteLLM SDK 和本机模拟接口做端到端验证，包含队列子进程语音主转写与复核，不加载原生 ASR；网络审计禁止对外连接。这是接口行为验证，不是识别质量评测。加 `--serve` 可在 `http://127.0.0.1:8766` 检查隔离测试界面，不改正式学习数据。
