# 本机验证结果

日期：2026-11-04。硬件：Apple M4 / 16 GiB 统一内存 / macOS 27.0.1。

## 真实模型验收

使用本项目生成的中英交替语法课视频，包含正确例句、故意错误例句、英文画面文字。没有对用户提供的 B 站视频完整音轨进行准确率测评。

| 项目 | 结果 |
| --- | --- |
| 混合课程音轨 | 28.5 秒及 57.1 秒两段素材均完成 |
| 长音频块 | 实际处理了 28 秒音频块；最大块长受限，不把整段长课放入模型上下文 |
| MiMo 4-bit GPU 峰值 | 57.1 秒测试约 7.65 GiB |
| Whisper Large-v3 GPU 峰值 | 约 3.36 GiB |
| 模型加载 | 使用本项目内权重和音频编码器，两个独立子进程顺序执行 |
| 离线验证 | 推理设置 HF/Transformers 离线模式，并用 Python audit hook 阻止 DNS 和 TCP 连接；两个进程均成功完成 |
| OCR | Apple Vision 识别原图；中英自动检测，文字纠正关闭 |
| 错误例句保留 | MiMo 及画面 OCR 均保留 `He go to school every day.` |
| 双模型分歧 | Whisper 在测试的部分混合片段中遗漏英文，界面正确列出分歧，未自动替换主识别 |
| 导出 | TXT / Markdown / SRT / JSON / 出题提示词均成功 |
| 来源隔离 | OCR 和字幕轨与口述分开附带，原始两份文本保留 |

GPU 峰值与进程 RSS 是不同口径，不相加。以上峰值来自测试任务；实际课堂、后台软件、系统版本和音频块内容会影响资源占用。单一模型或双模型均不能保证转写全部正确。

## 自动检查

22 项 unittest 通过，覆盖：导入校验、4 个任务容量、取消/重试/删除、取消同时终止子引擎、跨站请求拒绝、媒体 Range 回放、关键帧访问限制、禁止把编码器当识别器、全文保存、片段选择不覆盖人工全文、字幕保留原文、时间戳进位、分块边界、英文语法差异、来源导出、错误例句保留等。

`node --check static/app.js` 通过，`uv pip check` 检查的 75 个已安装包兼容。

## 操作验证

在实际本地界面中检查了默认 MiMo/中英混合设置、独立复核、画面资料、保留主识别和生成、预览出题资料及全选复制回退。测试素材保存在 `tests/assets/`，对应学习记录保存在 `data/jobs/`，可以在界面中回看。
